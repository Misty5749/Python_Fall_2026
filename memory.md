## What to ask or check next time

- Ask which requirement or behavior the student wants to work on first.
- Ask what they expect the program to do and what it currently does, including example input and output if there is a bug.
- Check the assignment instructions and nearby project examples before introducing a new Python feature or style.
- Clarify whether the student wants a hint, a walkthrough, debugging help, or a more complete example.
- After a change, help test one normal case and one invalid or edge case, and explain what the results show.
